# homebrew-tap

Homebrew tap for [eyesonly](https://github.com/jagritvats/eyesonly), per-user access control for git.

## Install

```sh
brew install jagritvats/tap/eyesonly
```

This installs the `eyesonly`, `git-eyesonly` and `eyesonly-server` commands. The formula depends on Homebrew's `node` (Node 22 or newer is required), which brew installs automatically if missing.

See the [main repository](https://github.com/jagritvats/eyesonly) for documentation and issues.
